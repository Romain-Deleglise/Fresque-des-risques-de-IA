Retours

Nous vous proposons deux moyens de nous faire vos retours :

  • sur une carte ou un lien précis : commentez directement la fresque de référence, plus bas ;
  • sur l'atelier ou le jeu en général : remplissez le formulaire, en bas de page.

La fresque de référence

Un exemple de fresque terminée. C'est une disposition possible parmi d'autres : il n'y a pas de fresque parfaite.

Pour commenter une carte ou ses liens, activez le « Mode commentaires », puis cliquez sur la carte concernée.

Votre retour sur l'atelier

Comment s'est passé votre atelier ? Ce qui vous a plu, ce qui a coincé, ce que vous changeriez : racontez-nous. Vos retours nous aident à l'améliorer. Merci d'avance !

Ce que les autres ont remonté

Un retour apparaît dès son envoi, grisé tant qu'il n'a pas été relu par l'équipe.
