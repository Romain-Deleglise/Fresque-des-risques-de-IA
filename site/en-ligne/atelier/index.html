Comment jouer

…

  • Cartes : « Piocher une carte » puis « Poser » ; sur le tableau, glissez-la. Le bouton ⤢ l'agrandit et permet de la retourner.
  • Liens : outil « Lien », cliquez la carte de départ puis celle d'arrivée. Cliquez le trait pour l'annoter ou le supprimer.
  • Notes : outil « Note » puis un clic sur le tableau. Glissez pour déplacer, cliquez pour éditer ; vide, elle disparaît.
  • Zoom : boutons + / − ou « Molette ». « Tout voir » recadre l'ensemble. Glissez une zone vide pour vous déplacer.

Le tableau se joue sur ordinateur

Cet atelier interactif est prévu pour un écran d'ordinateur. Retrouvez-le depuis un ordinateur, ou téléchargez les cartes pour animer en présentiel.
