Comment jouer

…

  • Déplacer : glissez une carte pour la déplacer ; glissez une zone vide pour vous déplacer sur le tableau.
  • Cartes : « Piocher une carte » puis « Poser ». Le bouton ⤢ l'agrandit et permet de la retourner.
  • Liens : cliquez « Lien », puis la carte de départ et la carte d'arrivée. Sélectionnez une flèche pour l'annoter, la supprimer ou la passer en double sens (↔).
  • Notes : double-cliquez sur une zone vide du tableau. Glissez pour déplacer, cliquez pour éditer ; vide, elle disparaît.
  • Zoom : molette, boutons + / − ou « Tout voir » pour recadrer.

Reconstituez la carte des risques de l'IA

Le but : relier les 38 cartes pour dresser, petit à petit, une vue d'ensemble — comment l'IA fonctionne, ce qu'elle sait faire, ses risques, et les réponses possibles.

  1. Piochez une carte : elles arrivent dans l'ordre, par lots (1 · fonctionnement → 2 · capacités → 3 · risques → 4 · risques majeurs → 5 · réponses).
  2. Placez-la sur le tableau (bouton « Poser » ou glisser), puis piochez la suivante.
  3. Reliez les cartes : outil « Lien », puis cliquez une carte de départ et une carte d'arrivée. Une flèche = « ceci entraîne / mène à cela ».

Il n'y a pas une seule « bonne » fresque : le but est de construire des liens qui ont du sens pour vous. Bloqué·e ? Agrandissez une carte (⤢) pour lire son explication au dos. Cet atelier se vit d'habitude à plusieurs avec un animateur ; le « ? » en haut rappelle tout à tout moment.

Le tableau se joue sur ordinateur

Cet atelier interactif est prévu pour un écran d'ordinateur. Retrouvez-le depuis un ordinateur, ou téléchargez les cartes pour animer en présentiel.
