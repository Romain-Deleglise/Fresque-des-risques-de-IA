Fresque en ligne

Animer la fresque à distance

La Fresque en ligne est en version d'essai.

Vous pouvez d'ores et déjà ouvrir une session, inviter des participants avec un code et construire la fresque sur un tableau partagé. Le service est jeune : merci de vos retours.

Ouvrir une session   ou essayer seul·e (démo)

Un bug, une idée ? Envoyez-nous un retour ✉

Comment ça marche

Une expérience pensée pour rester simple, sans compte ni installation :

  • L'animateur·ice ouvre une session et partage un code court avec le groupe.
  • Les participant·es rejoignent avec ce code et un prénom, rien de plus.
  • Les cartes sont distribuées, une par une ou à chacun, puis posées sur un tableau partagé.
  • On relie les cartes, on ajoute des notes ; la voix passe par un salon externe (Discord, Google Meet…).

Vos données

Aucun compte, aucune adresse e-mail : seul le prénom saisi pour rejoindre une session est utilisé, le temps de l'atelier. Les sessions sont automatiquement supprimées après quelques heures d'inactivité. Voir les mentions légales.

Préférez le présentiel ?

Le matériel imprimable est disponible dès maintenant : téléchargez les cartes et réunissez un groupe autour d'une table.
