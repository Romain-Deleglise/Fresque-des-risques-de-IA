    Comment ça marche
    Cartes : l'animateur distribue ; posez votre carte, puis glissez-la. Le bouton ⤢ l'ouvre en grand.
    Liens : outil Lien, cliquez la carte de départ puis celle d'arrivée. Cliquez le trait pour l'annoter ou le supprimer.
    Notes : outil Note puis un clic sur le tableau ; glissez pour déplacer, videz pour supprimer.
    Vue : zoom et déplacement sont propres à chacun. « Tout voir » recadre l'ensemble.
