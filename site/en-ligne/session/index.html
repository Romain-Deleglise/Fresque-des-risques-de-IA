    Comment jouer

    …

    • Déplacer : glissez une carte pour la déplacer ; glissez une zone vide pour vous déplacer.
    • Cartes : l'animateur met des cartes dans le pool commun (en bas) ; chacun·e clique « Poser » pour l'amener sur le tableau. Le bouton ⤢ agrandit une carte.
    • Liens : cliquez « Lien », puis la carte de départ et la carte d'arrivée. Sélectionnez une flèche pour l'annoter, la supprimer ou la passer en double sens (↔).
    • Notes : double-cliquez sur une zone vide du tableau ; glissez pour déplacer, videz pour supprimer.
    • Vue : molette pour zoomer ; zoom et déplacement sont propres à chacun. « Tout voir » recadre.
    Cliquez une carte pour l'ajouter au pool commun (8 max), que tout le monde peut poser.
