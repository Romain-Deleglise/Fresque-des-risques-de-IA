Comment participer à un atelier ?

Pour participer à un atelier, rien de plus simple : il suffit de rejoindre un atelier programmé. Parcourez la liste ci-dessous, en ligne comme en présentiel, et inscrivez-vous à celui qui vous convient. Rien à préparer et aucun prérequis technique.

Ateliers

Ateliers programmés

Choisissez un atelier public et inscrivez-vous : vous recevrez un e-mail de confirmation avec le code de session, la date et l'heure (et le lieu exact si présentiel).

Programmer un atelier

Choisissez le format, la date et le nombre de places. Vous recevez un e-mail de confirmation avec le code de session. Un atelier public apparaît ci-dessus ; un atelier privé reste connu de vous seul·e (donnez le code vous-même). Pour un atelier en ligne, le jour J vous ouvrez la session en direct avec ce code depuis la Fresque en ligne.

Format

Annuler un atelier

Une erreur de saisie ? Saisissez le code de session et l'e-mail de l'animateur·ice pour le retirer de la liste. (Le lien reçu par e-mail permet aussi de l'annuler en un clic.)
