Déposez ici les `.woff2` (sous-ensembles latins) référencés par
`assets/css/fonts.css` :

- `saira-condensed-700.woff2`
- `montserrat-400.woff2`, `montserrat-700.woff2`, `montserrat-900.woff2`
- `roboto-slab-300.woff2`
- `caveat-400.woff2`

absents, les replis système définis dans `site.css` s'appliquent.
