# Visuels des cartes — dossier de dépôt

Déposez ici les images **haute résolution** (impression) des cartes, telles que
fournies par Pause IA (les ~40 fichiers PNG/JPG). C'est la **source** ; les
variantes web optimisées (`560 px` et `900 px`, format WebP) sont générées à
partir d'ici vers `site/assets/img/cartes/` (voir B3.7).

## Comment déposer

1. Copiez vos fichiers dans ce dossier (`contenus/cartes/`).
2. **Renommez-les** selon le numéro de carte, sur deux chiffres : `01.png`,
   `02.jpg`, … `38.png`. L'extension d'origine est conservée.
3. Générez les variantes web (voir `scripts/` ou la procédure du README racine).

Tant que les variantes web ne sont pas générées, le site affiche un cadre neutre
avec le titre (dégradation propre, A15.1) — rien ne casse.
